# API de Agregação de Dados Climáticos e Geográficos

Esta é uma API REST desenvolvida em Node.js e Express para a disciplina de Técnicas de Integração de Sistemas (N703). A aplicação consome APIs públicas externas (Open-Meteo e Brasil API) para agregar e padronizar dados climáticos e geográficos.

## 🚀 Como Executar o Projeto

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina o [Node.js](https://nodejs.org/).
